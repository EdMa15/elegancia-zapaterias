# elegancia-zapaterias
Sitio web de Elegancia Zapaterias. El diseño de este sitio fue creado por mí tomando inspiración de un video en YouTube sobre diseño de páginas para e-commerce. Una buena parte del código fue sugerida o modificada por ChatGPT para mejorar su limpieza y, en el caso del script, para añadirle una mejor funcionalidad.
